# 花果山
阵容特色：花果山通过提供属性成长的部将或【神通】，来使具有【协战】特性的部将触发【协战】，进而使花果山的所有部将获得持续的属性成长。
## 后援神通流 
### 成型阵容
美猴王、大猿神、大猿神、白猿领军、跑山猢狲、参禅心猿、禄星
### 阵容玩法
在成型后通过跑山猢狲的后援获得大量神通资源，释放大量神通触发白猿领军与参禅心猿的效果，从而触发美猴王跟大猿神的协战效果获得全体的属性增益。
### 适合开局
 在选到以下一些大圣的时候玩这个阵容会有额外的优势：
 经济型：申公豹、文财神、敖灵、镇元子等
 战力型：白龙马
### 适合法宝
在选到以下法宝之后玩这个阵容会有额外的优势
灵宝天书（每回合固定额外获取神通资源）、禄星高照像（直接获取禄星，帮助搭建阵容）、龙宫聚财（增加经济与手牌上限，后援触发后能获得更多的神通资源）等
### 前期过渡
1~3本 激进策略/保守策略 
可以使用鼓猴（或农夫等能触发协战的部将）+小猴精+兔半仙作为优质过渡，也可以使用其他阵营的过渡牌
### 中期找牌节奏与策略
- 在商店4级找到石猴，5级（8~10回合之间）找到美猴王跟参禅心猿/禄星之后可以选择这套为目标阵容
- 在五本停留1~2个回合寻找美猴王跟参禅心猿/禄星并提升场面战力
- 升级商店到6级，继续寻找阵容目标的部将

# 迦楼罗
迦楼罗非常考验操作者的决策和操作能力，能否拿到【飞行】流派的关键卡【大龙神】、【大羽神】或【抢攻】流派的关键卡【幻羽】，并且如何快速提高关键卡牌的属性是取胜的关键。
# 大唐
大唐拥有最多的部将数量，可提供最多的辅助能力，也最灵活多变。可通过唐王和持续获得经济优势的部将，打造跨阵营的阵容。
# 狮驼岭
狮驼岭擅于提升商店部将属性，然后由阵中部将吞噬商店部将来获得属性成长。
# 地府
地府属于高攻低血的阵营，通过冥府女帝、冤魂、鬼魂神通、夜游神增强地府部将的攻击力；再在战斗中不断召喚地府部将，以获得战场上的优势
# 阿修罗
阿修罗是卖血的阵营，战争巨象在大圣受到伤害时可以为友方部将提供大量属性。通过部将的购买、登场、商店刷新、等机制扣除大圣血量，再配合鬼将将伤害降为0，达成完美的循环。
# 灵山

最终阵容：
灵山通过叠加【灵力】来增加法术伤害，往往和【残念】进行搭配。通过地藏王菩萨提前触发已方【残念】可以先手造成大量法术伤害，并在后续通过【转生】大量叠加【业报】触发大日如来的被动效果。布阵时，要考虑保护核心部将。
# 龙宫
龙宫擅于培养龙魂属性，并将龙魂属性附加给龙宫部将来极大的提升作战能力。核心部将东海龙王也可源源不断的召唤神龙，配合龙宫太子能将龙魂收益成倍放大。
